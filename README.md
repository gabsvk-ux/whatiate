# whatIAte

whatIAte is a personal food diary for Android. It records what was eaten at each meal of each day, with an optional photo.

It is a private app made for its author's own use. It is not distributed through any app store.

## What it does

- Keeps a diary of meals, day by day, on the phone.
- Can remind you to record a meal.
- Can copy the diary to a folder in your own Google Drive as a backup, if you switch that on.
